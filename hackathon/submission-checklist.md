# Submission Checklist

## Product
- [ ] End-to-end vertical slice works from a clean environment.
- [ ] Genuine artifact passes verification.
- [ ] Tampered artifact fails verification.
- [ ] Live web verifier is reachable.
- [ ] CLI instructions work from README.

## 0G evidence
- [ ] 0G Storage root captured.
- [ ] Storage upload transaction captured.
- [ ] Storage retrieval/proof demonstrated.
- [ ] 0G mainnet registry contract deployed.
- [ ] Contract address recorded.
- [ ] Deployment transaction recorded.
- [ ] Real build registration transaction recorded.
- [ ] Sandbox/Tapp execution evidence recorded accurately.

## Repository
- [ ] Public visibility.
- [ ] Excellent README.
- [ ] Architecture diagram.
- [ ] Setup instructions.
- [ ] Tests passing.
- [ ] No secrets/history leaks.
- [ ] Working-name/branding decision resolved enough for submission.

## Demo
- [ ] 90-second script rehearsed.
- [ ] Screen recording readable on mobile.
- [ ] No waiting on slow build in the recorded path unless intentional.
- [ ] Evidence links shown.
- [ ] Tamper moment clearly visible.

## AKINDO
- [ ] Re-read live rules/deadline.
- [ ] All mandatory fields complete.
- [ ] Required project links present.
- [ ] Required social/demo media complete.
- [ ] Final submission saved before deadline.
