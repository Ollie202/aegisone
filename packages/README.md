# packages

Implemented M1 packages:

- `core` — provider-independent source claims, validation, SHA-256, canonical manifests, and deterministic comparison;
- `runner-local` — exact-commit controlled-fixture reproduction with time/path/output constraints;
- `cli` — local verification orchestration and stable JSON output.

0G-specific adapters are added only as their real milestone integrations are proven. See `docs/03-architecture.md` and `planning/current-sprint.md`.
