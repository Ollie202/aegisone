# Brand / Naming Risk

## Status

**ProofRail is a working name only.**

## Finding

As of 2026-08-16, an active public GitHub organization/repository already uses `ProofRail/proofrail`. That project describes itself as a vendor-neutral evidence and reliance framework for agentic AI control and published a concept paper in July 2026.

This is not the same product, but both projects occupy trust/evidence/verification language. That creates avoidable search, identity, and future branding confusion.

Reference: https://github.com/ProofRail/proofrail

## Decision for now

- Do not claim brand ownership.
- Do not buy branding assets/domains around the name yet.
- Repository may use a temporary descriptive slug if needed.
- Resolve final product name before serious public launch or long-term marketing.

## Naming criteria for replacement

A future name should be:
- distinctive in GitHub/web search;
- not obviously used by another security/provenance product;
- short enough for a CLI command;
- usable for protocol/network language;
- not tied exclusively to 0G so the project can outlive one hackathon.
